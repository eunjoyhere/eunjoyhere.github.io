04 / How I approach a problem

From curiosity
to a model.

복잡한 문제일수록 기본으로 돌아갑니다. 데이터와 문제를 먼저 이해하고, 단순한 기준 모델에서 출발해 실험과 검증을 반복하는 태도를 지향합니다.

01

Define the problem

무엇을 예측하거나 분류할지, 성공을 어떤 지표로 판단할지 정의합니다.

02

Understand the data

데이터의 분포와 누락, 편향 가능성을 확인하고 학습·검증 데이터를 설계합니다.

03

Build & experiment

기본 모델부터 시작해 구조와 하이퍼파라미터를 바꾸며 학습 과정을 관찰합니다.

04

Evaluate & explain

성능 수치뿐 아니라 일반화 가능성과 한계를 함께 검토하고 결과를 설명합니다.
